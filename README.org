* selfdidactic/switchyard
:PROPERTIES:
:CUSTOM_ID: selfdidacticswitchyard
:END:

Switchyard is a non-interactive Clojure CLI that loads a specification
document for processing. Specifications may use Markdown or Org format.

** Installation
:PROPERTIES:
:CUSTOM_ID: installation
:END:
Clone or download the project from
https://github.com/selfdidactic/switchyard and install Clojure CLI.

** Usage
:PROPERTIES:
:CUSTOM_ID: usage
:END:
Run the CLI from source:

#+begin_example
$ clojure -M:run-m --spec path/to/spec.md
#+end_example

A successfully loaded specification produces no output and exits with
status =0=. The CLI accepts =.md=, =.markdown=, and =.org= files;
extensions are matched case-insensitively. This version loads the complete
document but does not yet parse or transform its contents.

Running without arguments displays help:

#+begin_example
$ clojure -M:run-m
Usage: switchyard [options]
...
#+end_example

Build the uberjar:

#+begin_example
$ clojure -T:build ci
#+end_example

Then run the same CLI from the generated jar:

#+begin_example
$ java -jar target/net.clojars.selfdidactic/switchyard-0.1.0-SNAPSHOT.jar --spec path/to/spec.org
$ java -jar target/net.clojars.selfdidactic/switchyard-0.1.0-SNAPSHOT.jar --version
switchyard 0.1.0-SNAPSHOT
#+end_example

** Options
:PROPERTIES:
:CUSTOM_ID: options
:END:
#+begin_example
-h, --help       Show help for using the program
-v, --version    Show the program version
-s, --spec PATH  Load the specification document at PATH
#+end_example

Help takes precedence over every other option. Version takes precedence over
specification loading and command-line errors when help is not requested.

** Exit codes
:PROPERTIES:
:CUSTOM_ID: exit-codes
:END:

- =0=: help or version was displayed, or a specification was loaded
  successfully.
- =1=: the specification format is unsupported, the file is unavailable, or
  the file could not be read.
- =2=: the command line is invalid, such as an unknown option, missing option
  value, positional argument, missing specification, or repeated =--spec=.

** Development
:PROPERTIES:
:CUSTOM_ID: development
:END:

Start a REPL in the =selfdidactic.switchyard= namespace:

#+begin_example
$ clj -M:repl
selfdidactic.switchyard=>
#+end_example

Run the tests:

#+begin_example
$ clojure -T:build test
#+end_example

Run the complete CI task and rebuild the uberjar:

#+begin_example
$ clojure -T:build ci
#+end_example
